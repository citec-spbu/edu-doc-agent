## Методика и ограничения

- Эталон XLSX-плана зафиксирован до первого сравнения. Он собран отдельным reference reader через ZIP/XML, без openpyxl, парсера и экстрактора. Области листа и правила контекста заданы по исходнику; хеш запрещает применять эту разметку к другой версии файла.
- Использован существующий полный локальный эталон матрицы. Его происхождение описано в eval/matrix_gold.py: независимое чтение XML.
- Независимой полной проверки человеком и теста на новой программе нет. Это локальная сверка с программно подготовленным эталоном и регрессия на документах разработки, а не оценка обобщения.
- Entity-level дисциплина сравнивает код и название; контекст отдельно входит в отношения и record.discipline_complete (все 16 полей PlanEntry). Перестановка часов по видам должна снижать полевую метрику и полноту записи.
- Для источников сравниваются исходная строка, лист, код и нормализованное название. Типографские варианты тире не считаются ошибкой координат.
- Для разреженной матрицы отдельно учитываются положительные связи: высокая доля верных нулевых ячеек не заменяет relation-F1.
- Формулы не пересчитывались: проверяются сохранённые значения. Ошибки и отсутствие кэша проверяются также синтетическими регрессиями.
- DOCX и XLSX плана разных версий не сравниваются как один эталон. Междокументное сопоставление и span-level NER здесь не оцениваются.
- Полные исходники, эталоны, ответы и ошибки остаются в data/evaluation. JSON сохраняет базовый Git-коммит и SHA-256 каждого файла кода рабочего дерева.

## Доработки по ревью PR #45 (26 ноября 2026)

Извлечение сохраняет записи при следующих правках Excel:

- Дисциплина без кода, с компетенцией или формой контроля, остаётся в группе выбора,
  даже если нагрузка пуста или содержит ошибку формулы.
- Для присоединения отдельной строки перевода требуется общее вертикальное объединение
  предметного поля, кроме кода блока. Собственные поля нагрузки отличают самостоятельный
  английский курс от перевода соседнего курса.
- Повторная шапка обновляет столбцы названия, контроля и групп часов, сохраняя семестр,
  год и текущий контекст. Переносы строк в названиях столбцов нормализуются.
- Заметки справа от таблицы не меняют контекст семестра и не открывают раздел ГИА:
  переход в ГИА требует полного набора столбцов шапки.
- Название группы со словом «Часть» сохраняет действующую часть учебного плана.
  Формулировка компетенции читается из столбца «Наименование», включая листы согласования.

Ошибка Excel остаётся предупреждением с листом и адресом ячейки; в предметные поля она
передаётся как неизвестное значение. Полностью совпавшие разделы на разных видимых листах
вызывают предупреждение с обоими именами листов. Записи обоих листов сохраняются,
чтобы пользователь мог выбрать рабочую версию.

Для записи из нескольких строк `source.line` указывает начало, `source.end_line` — последнюю
строку включительно, а `source.quote` содержит цитаты обеих строк. У однострочного источника
`end_line=null`. Это относится и к дисциплинам, и к процедурам ГИА. Историческая метрика
222/222 выше проверяет только основную строку; полноту цитат переводов отдельно проверяют
регрессии, включая локальный XLSX.

Синтетический `PLAN` вынесен в `tests/fixtures/curriculum_plan.py`: импорт и сборка теста CLI
не читают реальный корпус или архивы. Регрессии находятся в
`tests/unit/test_extraction_curriculum_xlsx.py`; локальные проверки пропускаются без архива.

Повторная сверка после исправлений на тех же исходниках и эталонах: **3613/3613** полей
плана, **6638/6638** полей матрицы; F1 всех измеренных групп — **1.0000**. Три повтора
дали детерминированный результат. Новый машинный результат остаётся локально в
`data/evaluation/xlsx_quality_review45.json`. Отдельные парные проверки правок U91, U168,

только её название у связанных дисциплин.
